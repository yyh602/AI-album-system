# 優化後的人臉裁切功能說明

## 🎯 概述

本次優化針對 `azure_face_detection.php` 中的人臉裁切邏輯進行了重大改進，實現了根據臉的大小自動調整邊框的智能裁切功能。這將顯著提升人臉向量提取的品質和準確性。

## ✨ 主要改進

### 1. 智能邊框調整算法

#### 🔍 小臉 (≤ 80px)
- **邊框大小**: 5px
- **適用場景**: 合照中的人臉
- **優點**: 減少背景干擾，更聚焦臉部特徵
- **品質提升**: 提升特徵提取準確性

#### 🎭 中等臉 (80-250px)
- **邊框大小**: 5-30px (線性插值)
- **適用場景**: 日常照片
- **優點**: 動態調整，平衡細節和背景
- **品質提升**: 平滑過渡，避免突兀變化

#### 📸 大臉 (≥ 250px)
- **邊框大小**: 50px
- **適用場景**: 自拍或特寫照片
- **優點**: 包含更多臉部特徵和頭髮
- **品質提升**: 完整特徵保留

### 2. 線性插值計算

對於中等臉，使用線性插值公式：

```
margin = 5 + ((faceSize - 80) / (250 - 80)) * (30 - 5)
```

這確保了邊框大小在 80-250px 範圍內平滑過渡，避免了固定值的突兀變化。

### 3. 邊界檢查優化

- 使用 `max(0, ...)` 確保裁切區域不超出左邊和上邊
- 使用 `min(imageWidth, ...)` 確保裁切區域不超出右邊和下邊
- 自動調整裁切尺寸以適應邊界限制

### 4. 增強的信息輸出

每個人臉裁切結果現在包含：
- `face_size`: 原始臉大小
- `margin_used`: 使用的邊框大小
- `crop_dimensions`: 最終裁切尺寸
- 詳細的錯誤日誌和統計信息

## 🚀 技術實現

### 核心方法

#### `extractFacesFromImage()`
主要的裁切邏輯實現，包含：
- 智能邊框計算
- 邊界檢查
- 品質控制
- 重複人臉檢測

#### `suggestOptimalCropParameters()`
提供裁切參數建議，幫助調試和優化。

#### `getCropStatistics()`
獲取裁切統計信息，監控系統性能。

### 品質控制參數

- **最小人臉尺寸**: 50px
- **最大人臉尺寸**: 800px
- **重複檢測閾值**: 0.45 (IOU)
- **JPEG 品質**: 90%

## 📖 使用方式

### 基本使用

```php
require_once 'azure_face_detection.php';

$faceDetection = new AzureFaceDetection();
$faces = $faceDetection->detectFaces($imageUrl);
```

### 獲取裁切建議

```php
$suggestions = $faceDetection->suggestOptimalCropParameters(150);
echo "建議邊框: " . $suggestions['margin'];
echo "原因: " . $suggestions['reason'];
```

### 查看統計信息

```php
$stats = $faceDetection->getCropStatistics();
echo "總處理人臉數: " . $stats['total_faces_processed'];
```
